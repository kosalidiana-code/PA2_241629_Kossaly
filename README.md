# PA2 - Matrix Transformations and Perspective

Student ID: 241629

## Variant Parameters

- Solid: Pentagonal prism
- Orbit period: 15 seconds
- Cube spin axis: normalized (1, 1, 1)
- Orbit plane: horizontal around the Y-axis
- Camera eye: (5, 3, 5)
- Initial FOV: 60°

## How to Run

Open the project in VS Code and click Go Live. The project will open in the browser.

## Controls

- P — Pause / resume animation
- O — Toggle perspective / orthographic projection
- + or = — Increase FOV by 5°
- - — Decrease FOV by 5°
- Left Arrow — Rotate camera left by 5°
- Right Arrow — Rotate camera right by 5°
- R — Reset camera and time
